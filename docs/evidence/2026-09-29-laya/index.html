04 / What changed

Local by default. Explicit about limits.

Laya defaults and portable tools

The primary bundle and installed smart tool use local Laya. Search and computer-use proposals are available to all four harnesses. AnyJev is outside the default path. Existing sessions and cached bundles need a refresh.

Robustness fixes and failed attempts

Missing model identity is rejected. Escaped source is chunked within input limits. Oversized UI snapshots defer. The native test profile now names its filesystem source explicitly to avoid an Amplifier loader ambiguity. OpenCode needed an available, authorized model after three failed configurations.

Reproduce the portable smoke

python3 scripts/laya-smoke.py --output /tmp/laya-smoke-new

Requires the installed CLI, ripgrep and a running Laya service. Run through each harness's shell tool. Inspect results: a successful invocation may still abstain. The smoke does not control a desktop.

What this evidence does not establish

Automatic tool adoption, reliable accepted computer actions, broad search accuracy and equal-quality savings remain unproven. The separate SWE-bench campaign is still awaiting reconciliation.

The next bar is usefulness.

Do not lower confidence gates to make a demonstration pass. Measure accepted actions, task quality, complete wall time and total spend against a matched baseline.
