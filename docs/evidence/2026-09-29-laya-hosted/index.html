What would make
Laya useful?

A small model trained for a narrow, repeated decision could avoid an expensive reasoning call. The current checkpoints have not demonstrated that benefit for our bundle.

Use deterministic rules for exact matches and eligibility. Test domain-trained models for semantic decisions, with abstention and the existing host permissions.

Methods, limits and provenance

Two option-order passes per case; summary scores use only the first pass. Hand-authored labels without an independent human audit. The fresh set was frozen before inspecting specialized-checkpoint results, after the original base/Jev test. No confidence tuning or retries.

Tokenization audit found no truncation in the original 60 cases. Local and hosted base Laya agreed on all 120 responses. Typed model ran in process on MPS; its timing is not compared with HTTP latency.
